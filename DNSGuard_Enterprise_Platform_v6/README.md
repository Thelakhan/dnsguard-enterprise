# DNSGuard Enterprise - Multi-File Unified Platform

A professional-grade, multi-file DNS tunneling detection platform supporting concurrent PCAP and CSV ingest.

## New Features
- **Multi-File Upload**: Select and upload multiple `.pcap`, `.pcapng`, or `.csv` files simultaneously.
- **Combined Analysis**: Automatically merges records across all uploaded files to establish a unified timeline and correlative threat score.
- **Binary/Garbage Sanitization**: Automatically filters non-printable bytes from DNS queries for clean dashboard readability.
